# Zhuwa.Moolre.Sdk documentation

An unofficial .NET client for the [Moolre](https://docs.moolre.com/) API. These guides show how to use it in your own app.

| Guide | What it covers |
| --- | --- |
| [Getting started](getting-started.md) | Install, register, make your first call, sandbox and live |
| [Configuration](configuration.md) | Every setting, keys per Moolre service, reading settings from configuration, several wallets |
| [Payments](payments.md) | Mobile money collection (with OTP), payment status, payment links, Payment IDs, bank collections |
| [Transfers](transfers.md) | Name check, transfers to mobile money and banks, wallet-to-wallet transfers, transfer status |
| [Accounts](accounts.md) | Wallet balance, wallet settings, transaction history, sandbox wallets |
| [Sales](sales.md) | Airtime and data bundles, the bundle list, sale status |
| [SMS](sms.md) | Sending SMS, delivery status, sender IDs, SMS balance |
| [WhatsApp](whatsapp.md) | Templates, template messages, delivery status |
| [Payment webhooks](webhooks.md) | Receiving Moolre's payment callbacks safely |
| [Errors and money safety](errors.md) | Every exception, what to do after an unknown outcome, retries |
| [Testing your code](testing.md) | Replacing the SDK with test doubles in your own tests |
| [API reference](reference.md) | Every method: signature, description, parameters, request fields, exceptions |
| [Architecture](architecture.md) | How the SDK works inside, with diagrams, and the repository layout |

> This project is independent. It is not affiliated with, endorsed by, or supported by Moolre. For Moolre's own rules (limits, fees, approvals), Moolre's documentation is the source of truth.
